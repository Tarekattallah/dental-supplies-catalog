# Dental Supplies Catalog

متجر إلكتروني عربي لمستلزمات عيادات الأسنان — كتالوج منتجات، عربة تسوق، إتمام طلب، ولوحة إدارة للطلبات والمنتجات.

**🔗 الموقع:** https://tarekattallah.github.io/dental-supplies-catalog/

## المميزات

- **الرئيسية** — أقسام المتجر ومنتجات مميزة مع اختيار المقاس/الدرجة والإضافة للعربة مباشرة.
- **المنتجات** — بحث، فلترة بالقسم، العروض فقط، وترتيب بالسعر.
- **تفاصيل المنتج** — معرض صور، اختيار المواصفات، الكمية، وتفاصيل المنتج ووحدة البيع.
- **العروض** — المنتجات المخفضة مع نسبة الخصم المحسوبة تلقائياً.
- **العربة وإتمام الطلب** — تعديل الكميات والاختيارات، استلام من الفرع أو توصيل، والتحقق من رقم الموبايل المصري.
- **تأكيد الطلب** — رقم الطلب وملخص قابل للطباعة.
- **لوحة الإدارة** (`#/admin`)
  - الطلبات: بحث، فلترة بالحالة، عرض التفاصيل وتحديث الحالة.
  - المنتجات: إضافة منتج جديد بالصور والاختيارات والأسعار، تعديل المنتجات والعروض، والحذف.
- تصميم متجاوب بالكامل (RTL) للموبايل والتابلت والديسكتوب.

## هيكل المشروع

```
├── index.html            # الصفحة الرئيسية للتطبيق
└── assets/
    ├── css/style.css     # التصميم
    ├── js/data.js        # بيانات المتجر والمنتجات الافتراضية
    ├── js/app.js         # الصفحات، العربة، الطلبات ولوحة الإدارة
    └── images/           # صور المنتجات والواجهة
```

## التشغيل

لا يحتاج أي تثبيت — افتح `index.html` في المتصفح، أو ارفعه على أي استضافة ملفات ثابتة (مثل GitHub Pages).

## التخصيص

- اسم المتجر والعنوان: `STORE` في `assets/js/data.js`.
- المنتجات الافتراضية والأقسام والمدن: في نفس الملف.

> البيانات (العربة، الطلبات، تعديلات المنتجات) تُحفظ في متصفح المستخدم (localStorage).
